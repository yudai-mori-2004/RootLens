# RootLens データ保護・法務方針

本書は RootLens のデータ収集・販売に関する**法的判断を固める**ための方針文書である。実装(コード)に依存せず、判断を先に確定させ、実装・契約・UI はここから降りてくる仕様として位置づける。`DATA_SPECS_JA.md`(データパイプライン)/ `UI_SPECS_JA.md`(UX)と同列の Source of Truth とし、両者と矛盾する場合は本書の法的判断を優先する。

## 0. 位置づけと免責

- 本書は社内の意思決定を記録するものであり、最終的な法的助言ではない。§10 の項目は各主要法域(最低でも EU・米・日・中)の有資格弁護士のレビューを経て確定する。
- 確度タグ:
  - **【確定】** = これまでの検討で固まり、変更には積極的理由を要する。
  - **【推奨・要承認】** = 本書の推奨。代表者の承認をもって【確定】に昇格する。
  - **【要弁護士確認】** = 方向性は示すが、確定には専門家確認が必須。
- 本書が扱うのは「責任をどう負うか(=低減・移転・受容・証明の文書化)」であり、責任を消す方法ではない。責任の宛先と可動範囲は §6 に従う。

## 1. 基本方針(背骨)

### 1.1 合法性の土台は「同意」、匿名化は補助 【確定】

販売の適法化根拠は**撮影者の明示的同意**に置く。顔マスキング等の匿名化処理は、偶発的な第三者の母数を減らす**リスク低減層**であって、適法化根拠ではない。

理由: 当社は学習用に動画本体+詳細ラベルを販売するため、有用性と識別可能性がトレードオフの関係にある(学習に使えるほど匿名化は困難)。「匿名化したから個人データ法の射程外」という立て付け(類似事業者が採用)は、家庭内の濃密な映像では脆く、再識別が判明した瞬間に過去の販売が遡って違法になる。よって匿名化に賭けず、同意を背骨にする。

### 1.2 当社は controller である(実質優先) 【確定】

P2P 体裁・手数料モデル・KYC 情報の非保持・オンチェーンでのライセンス帰属といった形式は、**動画に映る人々の個人データ(= 第三者問題の本体)**についての controller 責任を一切軽減しない。当社が処理の目的(学習用販売)と手段(採点・パッケージ・マーケット・買い手契約)を決め、経済的利益(手数料)を得る以上、実質的に controller かつ販売者である。本書はこの自覚を前提とする。

- 区別: 撮影者の KYC 身元情報(KYC プロバイダ保持、当社非保持)と、動画コンテンツに映る人の個人データは別物。前者の最小化は有効だが、後者の責任は動かない。
- 「当社は processor にすぎない/撮影者が単独の controller」という主張は採らない(自社目的での処理のため成立しない)。

## 3. データとデータ主体の分類・取扱い階層 【確定】

映像に映りうる主体を再識別性で分類し、取扱いを固定する。販売ゲート(ステーク → ライセンス)に乗せる前に、この階層判定を通す。

| 主体 | 例 | 適法化 | 取扱い |
|------|----|--------|--------|
| **撮影者本人** | アプリ利用者 | 明示的同意(ステーク時) | プレビュー + 本人承認の上で**販売可** |
| **偶発の第三者**(他に識別手段が乏しい) | 一瞬映る宅配員・通行人 | 匿名化(補助層) | 顔/識別子マスキングで再識別不能化 → **販売可** |
| **識別可能な第三者**(継続的・文脈で特定される) | 同居家族・常連の来客 | 取得不能 | 検知 → **当該クリップを販売除外**(同意も信頼できる匿名化も無い) |
| **児童 / 違法 / 私的空間** | 子ども・裸・浴室等 | 同意で合法化不能 | 検知 → **ブロック + 検知時プロトコル**(§7) |
| **機微情報**(物体・環境) | 宗教物・薬・書類・画面 | 撮影者同意 + マスキング | 機微物体マスキング後に販売可。完全でないことを残存リスクとして受容(§7) |

原則: **同意も信頼できる匿名化も無いものは販売ルートに到達させない。** マスキングは「偶発分」の保険であって、識別可能な第三者・児童には使わない。

## 4. 再識別基準(当社が自らに課す閾値) 【推奨・要承認】

「匿名化(補助層)」が成立したと扱う条件を社内基準として定義する。

1. 顔・音声(録音する場合)・画面表示・書類/IDの個人識別情報をマスキングまたは除去していること。
2. 残った映像から、社内の再識別テストで対象個人の特定に至らないこと。
3. 上記を満たさない、または継続的に映る人物(家族等)は「匿名化済み」と扱わず、§3 に従い除外する。

再識別テストの方法・頻度・結果は記録する(§6 ④ 証明)。基準を満たさない場合の既定動作は「販売除外」とする(フェイルセーフ)。

## 5. 用語規律 【確定】

| 使わない語 | 使う語 |
|------------|--------|
| 匿名化済み / anonymized | 顔マスキング処理済み / de-identified / 識別子除去処理 |
| (個人データ法の)射程外 | (使用しない。同意を根拠として明示する) |
| いつでも完全削除 | 学習前は削除可能、学習後は以後の新規学習から除外 |

理由: 「匿名化済み」と過大表示すると、(a) ユーザー・買い手への不実表示リスク、(b) 「射程外だから義務不要」と自ら誤信して義務を怠る違法処理リスク、の二重の問題を生む。対外文書(LP / データセット記述 / ポリシー / 買い手契約)すべてに適用する。なお公開向け文章に内部設計プロセスを混ぜない既存方針も併せて守る。

## 6. 責任の負い方(4動作と可動範囲) 【確定】

「責任を負う」とは次の4動作を**事前に文書化**することと定義する。

| 動作 | 具体 | 対応文書 |
|------|------|----------|
| **① 低減 Reduce** | マスキング・検知→除外・空間除外・アクセス制御・保持期間 | §3, §4, DATA_SPECS |
| **② 移転 Transfer** | 保険、買い手契約の再識別禁止・賠償上限、撮影者への求償 | §9 ★8・★6 |
| **③ 受容 Accept** | 消せない残存リスクを代表者が受容・記録 | §7 |
| **④ 証明 Demonstrate** | ①〜③を事前に文書化し証跡を残す(説明責任原則) | 本書全体 + 台帳 |

最重要は **④**。同じ違反でも「記録なし=過失の違法処理(重い・悪質認定)」と「措置+残存リスク受容の記録あり=合理的措置済み(軽減・防御可能)」では帰結が大きく異なる。

**責任の上限の可動範囲(現実値):**

| 宛先 | 上限化 | 手段 |
|------|--------|------|
| 規制当局(制裁金) | **不可**(controller として自社が負う) | ① 低減が主、保険が補助 |
| 第三者本人の法定権利 | **不可**(契約に拘束されない) | ① 低減(発生させない) |
| 刑事責任 | **不可**(個人帰属・移転不能) | ① 低減(D4) |
| 買い手(B2B) | 可 | 契約で賠償上限・再識別禁止 |
| 撮影者(消費者) | 部分的 | 求償条項(回収は実務上限定的・消費者法で制約) |

結論: 契約は最後の薄い層。本体は **① 低減(同意も匿名化も無いものを販売に到達させない)** に置く。

## 8. 法域スコープ 【推奨・要承認】

全域同時提供はしない。取得地(撮影者所在)× 仕向け地(買い手所在)で経路を制御する。

| 法域 | 初期方針 | 理由 |
|------|----------|------|
| 日本 | **先行**(同意設計を前提に投入) | APPI 第三者提供はオプトイン同意で対応可。当社の同意設計と整合 |
| 米・生体規制州(IL/TX/WA 等) | **除外**(体制が整うまで) | BIPA 等の私人訴権・法定損害賠償の集団訴訟リスク |
| 米・全当事者同意州(CA/IL/FL/WA/PA/MD/MA 等) | **除外**(D2=音声記録のため) | 録音に全当事者同意が必要。家庭内の家族会話の録音が刑事リスクになりうる |
| 中国本土 | **除外** | 個人情報販売が刑事になりうる(PIPL + 刑法253条) |
| EU/EEA | **厳格モード or 後置** | controller 義務・削除権・越境が重く、体制完成後に投入 |
| 懸念国(中ロ等)向け移転 | **遮断** | 米バルク機微データ移転規制(該当する取得地のデータ) |

KYC(買い手の本人確認)を仕向け地ゲーティングに接続し、禁止経路をシステムで遮断する。

## 10. 弁護士レビュー必須・未決事項 【要弁護士確認】

方向性は示すが、確定には専門家確認を要する。

1. **ステーキングの証券性**: 経済的実態が「データ提供の対価」であることを契約文言・トークン設計で担保(投資契約=Howey に寄せない)。MiCA・送金業の評価も。
2. **ステーブルコイン支払い**: EU MiCA(EMT/ART)・米送金業/ステーブルコイン法制・選定通貨の規制適合。
3. **撮影者への支払いと労働者性**: ギグ分類リスク回避(指揮命令・専属性を持たせない)、課税・源泉・消費税。
4. **越境移転の手続**: SCCs / 十分性 / DPF、各取得地の越境規律。
5. **生体規制州・中国**: 除外設計(§8)の十分性、解除条件。
6. **同意の有効性**: 初回 ToS 包括同意への依存を脱し、販売・越境・機微情報への明示同意をステーク時同意へ統合する文言。
7. **消費者契約**: 求償・賠償制限条項の有効範囲(不公正条項規制・消費者契約法)。
8. **音声記録(D2)の盗聴法対応**: 全世界展開時、米・全当事者同意州(CA/IL/FL/WA/PA/MD/MA 等)での録音同意の取り方、声紋の生体規制(BIPA 等)該当性、会話内容の機微性の取扱い。日本先行段階での録音可否の最終確認も含む。
