# テスター向け同意 + 撮影ルール (tester-consent)

**種別**: 対ユーザー(軽量) / **状態**: ドラフト / **言語**: ja(正本)

アルファ(TestFlight)段階の軽量な同意文書。本番の [`privacy-policy`](../privacy-policy/ja.md) と [`terms-of-service`](../terms-of-service/ja.md) が整うまでの間、**撮影者本人から「集める・使う・社外にライセンス/販売する」ことへの明示同意**を取り、アルファ収集データを将来も合法的に使える状態にする。[`legal-policy`](../legal-policy/ja.md) の判断(D1/D2/D3/D4/D5/D6)を実装に落とす最小版。

## 0. 提示方式(層化同意)

同意は**2層**で提示する。

- **層1 = 要約(§2)**: 主婦等の非専門家にも分かる平易な文。**これ自体に拘束力はない**。理解を助けるためのもの。
- **層2 = テスター利用条件 正本(§3)**: 実際に同意の対象となる**拘束力のある全文**。アプリ内からいつでも全文を読めるようにする。
- 「同意して始める」を押した時点で、ユーザーは**§3 の正本全文に**同意したことになる。要約(§2)と正本(§3)が食い違う場合は **§3 が優先**する。
- 同意時に、**同意した §3 のバージョンとハッシュ、および表示した §2 要約のバージョンとハッシュ**を記録する([`consent-log-spec`](../consent-log-spec/ja.md))。

> 文言の原則: informed consent は「理解できること」が要件。だから層1は徹底して平易にし、**専門用語(ステーク/NFT 等)を出さない**。法的な完全性は層2が担う。

## 1. 適用範囲

- アルファ版 / TestFlight の全テスター。
- **撮影者本人のみが映る前提**(§3.4)。本同意は撮影者本人の分のみをカバーし、第三者の同意は代替しない。

## 2. 層1 — 画面表示:要約(非拘束)

実装はこの要約を画面に表示し、**同じ画面から §3 の全文(「利用条件を読む」)に必ず遷移できる**ようにする。

> **はじめる前に、確認してください**(これは分かりやすくした**要約**です。正式な内容は「テスター利用条件」にあり、「同意して始める」を押すと正式な内容に同意したことになります)
>
> - このアプリは、あなたが家事などをする様子を、頭につけたカメラで**映像と音声**として記録します。
> - 記録したデータは、AI やお家のロボットを賢くするための学習に使われ、そのために**社外の会社に提供・販売されることがあります**(日本国外の会社を含みます)。
> - 提供する前に顔などは自動でぼかしますが、**それで完全に分からなくなるとは限りません**。
> - だから **撮るのはあなた一人のときだけ**にしてください。
> - いつでもやめられます。学習に使われる前のデータは削除できます。**すでに学習に使われたデータは、その後の新しい学習からは外せますが、過去の学習はやり直せません**。
>
> ☐ 私は18歳以上で、この場所で撮影する権利があります
> ☐ 自分以外の人や子どもを映さないことに同意します
> ☐ **テスター利用条件(全文)を読み、同意します**(社外への提供・販売、日本国外への提供を含む)
>
> **[同意して始める]**  　**[利用条件を読む(全文)]**

## 3. 層2 — テスター利用条件(正本・拘束力あり)

これが同意の対象となる正式な文書。アプリ内から全文にアクセスできるようにし、同意時にこの版のバージョン+ハッシュを記録する(§4)。

### 3.1 記録するもの
頭部装着カメラの**映像と音声**、撮影構成により手ポーズ等のセンサー情報、機種・OS・アプリバージョン等の技術情報。

### 3.2 使い道
AI・ロボットの学習データの作成。そのために、**社外の会社・研究機関・AI 企業へのライセンス・提供・販売(日本国外を含む)**を行うことがある。

### 3.3 プライバシー処理(誇張しない)
提供前に顔などを自動でぼかす。ただし**完全に匿名化されるわけではない**(声・体つき・部屋の様子などから分かる場合がある)。当社はこのデータを「匿名化済み」とは称さない(D5)。音声を記録するため、**声も個人を識別しうる情報**として扱う(D2)。

### 3.4 撮影者の義務と表明保証(=撮影ルール)
撮影者は次を守り、提供する各クリップがこれを満たすことを表明・保証する。
- **自分一人のときだけ撮る**。家族・来客・友人など、ほかの人がいるときは撮らない。
- **子どもを映さない**。子どもが入ってきたら止める。
- **お風呂・寝室・トイレ・着替えは撮らない**。
- ほかの人や子どもがうっかり映ったクリップは**出さない(販売しない)**。
- テレビ・音楽・本・他人の作品などが大きく映る場面は避ける。
- 提供するクリップが、第三者の権利(肖像・パブリシティ・著作権等)を含まないこと。

### 3.5 取消し・削除(正直な範囲 / D6)
いつでも記録を中止できる。**学習に使われる前**のデータは削除できる。**学習に使われた後**は、以後の新規学習からは除外できるが、**過去の学習は取り消せない**。当社は「いつでも完全削除」とは約束しない。

### 3.6 第三者の扱い
第三者が映ったクリップは、撮影者の同意があっても**販売ルートに乗せない**(検知→除外。[`legal-policy`](../legal-policy/ja.md) §3)。本条件の「映さない」は一次防御であり、検知→除外/ブロックの代替ではない。

### 3.7 同意の対象
同意の対象は**本 §3 の全文**である。§2 の要約は理解のための補助にすぎず、本 §3 と食い違う場合は本 §3 が優先する。

### 3.8 適用範囲・地域
本条件はアルファの軽量版。[`legal-policy`](../legal-policy/ja.md) §8 で除外/厳格モードとされる地域(米・全当事者同意州、中国本土、EU 等)には、本軽量同意のままでは展開しない。

## 4. 記録する同意メタデータ([`consent-log-spec`](../consent-log-spec/ja.md) 参照)

同意成立時に、少なくとも以下を改竄しにくい形で記録する。
- テスター識別子(ウォレット公開鍵 / ユーザーID)
- 同意日時(UTC)
- **同意した §3 のバージョンとハッシュ**、**表示した §2 要約のバージョンとハッシュ**
- 同意したスコープ(収集 / AI学習利用 / 社外ライセンス・販売 / 越境提供)
- 3チェックの結果
- アプリ・端末情報

## 5. 限界・前提

- 本同意は**アルファの軽量版**。本番では [`privacy-policy`](../privacy-policy/ja.md) + [`terms-of-service`](../terms-of-service/ja.md) に置き換える。
- 第三者が映ったクリップは販売ルートに乗せない(§3.6)。
- 本同意より前に集めたデータは原則テスト専用・非売。
