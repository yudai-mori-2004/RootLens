# タスク 16: オンボーディング + 設定タブ

UI_SPECS_JA.md §7, §9 を実装する。

## オンボーディング (§9.1)

初回起動時の 5 ステップ:

1. **ウェルカム画面**: 3 枚カルーセルで概要説明
2. **KYC**: 第三者 KYC サービスへの遷移。完了まで撮影ロック
3. **利用規約同意**: 7 項目サマリ + 全文スクロール + チェックボックス
4. **マイク / カメラ権限**: 事前説明画面 → OS 権限ダイアログ
5. **チュートリアル**: 初回撮影モード進入時にインタラクティブ練習

ToS 更新時 (§9.2): 新 version 発行で Step 3 のみ再実行、同意まで撮影ロック。

## 設定タブ (§7.1)

| セクション | 項目 |
|---|---|
| アカウント | ウォレットアドレス、KYC 状態、ログアウト |
| 通知 | push 通知オン/オフ |
| 撮影 | BGM トラック選択、ハンドトラッキングオーバーレイ表示オン/オフ |
| データ | ストレージ使用量、キャッシュクリア |
| サポート | お問い合わせ、利用規約、プライバシーポリシー |
| アプリ情報 | バージョン、ライセンス |

## KYC サービス選定

検討候補: Persona, Sumsub, Onfido。
選定基準: iOS SDK 提供、日本在住対応、Solana wallet との紐付けが可能。

## 完了条件

- 初回起動で 5 ステップのオンボーディングが通る
- KYC 未完了で撮影モードに入れない
- 設定画面でウォレットアドレス表示、BGM トラック変更ができる
