# タスク 14: 撮影モード (対話 + カメラサブモード)

UI_SPECS_JA.md §4, §5, §6 を統合して撮影モード全体を実装する。
task 12 (録画パイプライン) と task 13 (音声エージェント) が前提。

## 2 つのサブモード (§2.2)

```
撮影モード
  ├─ 対話サブモード   ← カメラタブ押下で入る
  │    音声 AI 対話、タスク選択、カメラプレビュー常時表示
  │
  └─ カメラサブモード  ← タスク確定後
       録画中、ジェスチャー操作のみ、BGM フィードバック
```

## 対話サブモード (§4)

- フルスクリーンカメラプレビュー + ハンドトラッキングオーバーレイ
- 上部トースト (AI 応答) + 下部トースト (ユーザー発話)
- ヘッダー: 戻るボタン + ハンバーガーメニュー (タスク手動選択)
- 「ヘイレンズ」→ 音声対話 → タスク選択 → 「始めて」→ カメラサブモード遷移

## カメラサブモード撮影シーケンス (§5.3)

1. **オープンパーム検出**: 両手 42 landmarks が 1 秒間フレーム内 → 検出音
2. **VLM 開始条件チェック**: スナップショットを Claude に送信 → 合格/不合格
3. **カウントダウン**: 3, 2, 1 (毎秒カウント音)
4. **録画中**: BGM 再生、手のフレームイン/アウトで音量連動 (§6.2)
5. **サムズアップ検出**: 両手 thumbs-up 1 秒 → 停止音
6. **VLM 終了条件チェック**: 達成確度取得
7. **結果通知**: 音声入力再有効化、「送って」/「撮り直す」で分岐
