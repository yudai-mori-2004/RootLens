# RootCap

入力: 額の仮想曲率、額当ての幅・高さ、支持板と円形窪みの寸法。

出力: 黒PLA一体成形を想定した額当て曲面 + 固定支持板の STL。

## 現行モデル

現行は `r7-forehead-magsafe/`。印刷に使用する正本は次の2ファイルだけとする。

- `r7-forehead-magsafe/RootaCap_R7_print_final.blend`
- `r7-forehead-magsafe/RootaCap_R7_print_final.stl`

## 過去モデル

R1–R3は初期検討、`r4-simple-pocket/`は帽体を使う旧構成、`r5-forehead-tile/`は額当て試着モデル、`r6-forehead-magsafe/`はR7の基礎になった旧世代として保持する。R7の途中成果物はGit履歴に退避し、作業ツリーには残さない。
