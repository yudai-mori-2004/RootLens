# RootCap R3 conformal bridge

入力: 写真から仮定した短い bump-cap シェル、ケース込み横向きスマホ、M4/M5/M6 金具。

出力: シェル全面に沿うクラウンサドル、左右内側プレート、5段階ピッチヨーク、ケースごと差し込むスマホポケットの STL。

実行: `tools/rootcap/r3-conformal-bridge/build.sh`

## 試作の前提

- カウンターウェイトと後頭部ホルダーは設けない。
- サドル下面は仮のシェル楕円面と同じ曲面で、中央を浮かせない。
- `interface_pad = 0.8` は薄い EVA / TPU 分。直接密着なら `0` にする。
- シェル寸法は写真からの仮値。`shell_radius_x/y/z`、固定位置、接触長を冒頭で変更できる。
- スマホは横向き。標準45°、25°から65°まで10°刻みの実穴で固定する。
- スマホは横向きのまま、開放された長辺上部からポケットへ落とし込む。
- 初回試作では蓋・キャップ・ストラップを設けない。
- ポケット内側の軟質ライナーで個人ケースの数mmの差を吸収する。
- ケース込み幅145–185 mm、高さ70–96 mm、厚さ8–18 mmをパラメータ範囲とする。

## 印刷部品

- `crown_saddle.stl` ×1
- `inner_backer_left.stl` / `inner_backer_right.stl` 各×1
- `pitch_yoke.stl` ×1
- `phone_pocket.stl` ×1

試作は PETG、0.2 mm層、外周5、30–40% infillを初期値とする。サドルは側面を下にして配置し、内側プレートは凹面を上、ヨークは底面を下にする。

## 金具

- M4 シェル固定ボルト、ナット、大径ワッシャー ×4
- M4 熱圧入インサート ×4、M4皿ねじ ×4（ヨーク固定）
- M6 ボルト・ナイロックナット ×1（主軸）
- M5 ボルト・ノブナット ×1（角度固定）

`review/pocket-open-top.png` は上面を開放した空のポケット、`review/shell-contact.png` はサドルとシェルの接触形状、残り3枚は45°時の組立確認用。確認図にスマホ本体のモデルは含めない。写真のHEIC原本は生成処理に含めず、読み取り専用の参照として扱う。
