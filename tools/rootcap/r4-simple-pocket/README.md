# RootCap R4 adjustable arch pocket

入力: IMG_0270 の2枚構成、内寸 151 × 73 × 10.2 mm、写真から仮定した bump-cap シェル曲面。

出力: 印刷済みカメラカバーと互換の関節一体トレー、シェル密着アーチの STL。

実行: `tools/rootcap/r4-simple-pocket/build.sh`

`camera_cover.stl` は外形と位置合わせピンを維持し、スマホを押さえる広い面と、カメラ側の60 × 69 mmの縦長窓を持つ。窓は内寸151 × 73 mmの右端側62 mmを露出し、奥行き58.01 mmのiPhone 17 Proカメラ台座に余裕を持たせる。トレーの装着者から見て右側には、端子位置の異なるスマホとケース付きUSB-Cプラグに対応する幅8.6 mm・高さ29.75 mmの閉じた六角形状貫通穴を設け、穴の前後に2 mmずつ柱を残し、上下端をサポート不要の45°斜面にする。トレーはSTLの向きのまま閉じた長辺と軸受の平面を下、アーチはSTLの向きのまま切断された側面を下にする。角度は片側の面セレーションにより5°刻みで調節し、M5 × 50 mmの主軸を緩めて回し、締めて固定する。トレーは8 mm程度のブリムを付ける。アーチは8〜10 mmのブリムを付け、関節耳を支えるツリー自動サポートを有効にし、「ビルドプレート上のみ」は無効にする。積層0.20 mm以下、外周4層以上を推奨する。背面アームを伸ばした配置は前下方30°〜55°でシェルとの非干渉を確認済み。アーチはM4 4本でシェルへ固定する。シェル半径は写真由来の初期値なので、最初のアーチ試着後に接触形状だけを補正する。
