# RootaCap R7 forehead MagSafe mount

現在印刷に使用するRootaCapの正本。額接触部は幅96 mm、厚さ2.0 mmで、M4用の直径4.5 mm貫通穴を3個備える。額に接する面には、直径8.4 mm・深さ1.0 mmのねじ頭用窪みがある。外側は貫通穴だけで、ねじ頭用窪みはない。

## 正本

- `RootaCap_R7_print_final.blend` — 最終形状のBlenderファイル
- `RootaCap_R7_print_final.stl` — 印刷用STL

両ファイルの形状寸法は96.0 × 83.52585 × 50.72124 mm。STLは単一の閉じた形状で、境界エッジと非多様体エッジは0。

## 編集用ファイル

- `RootaCap_R7_editable_source.blend` — ブーリアン用オブジェクトを含む設計作業ファイル

印刷時は編集用ファイルから書き出さず、上記の `RootaCap_R7_print_final.stl` を使用する。過去のR7中間ファイルは作業ツリーから削除済みで、必要な場合はGit履歴 `62163ed` から参照できる。
